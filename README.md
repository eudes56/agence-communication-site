# Site WEND KUNI MINING CONSULTING INTERNATIONAL SARL

Pour visualiser le site localement :

1. Ouvre le dossier du projet dans VS Code.
2. Clique sur le fichier index.html.
3. Utilise l’option "Open with Live Server" si l’extension est installée.
4. Sinon, ouvre le fichier dans ton navigateur en double-cliquant sur index.html.
